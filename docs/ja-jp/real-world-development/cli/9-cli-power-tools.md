多くの CLI ツールと同様に、GitHub Copilot CLI には対話に使えるスラッシュコマンドが多数用意されています。コマンドを使うと、高度な機能、内部情報、追加の設定オプションを利用できます。これまでに `/diff`、`/mcp`、`/skills`、`/agent`、`/pr` などのコマンドを使いました。ここでは、ほかの便利なコマンドをいくつか見ていきましょう。

このレッスンでは、次のことを行います。

- `/context` と `/compact` を使い、Copilot が会話のコンテキストをどう管理するかを確認します。
- `/model` を使い、利用できるモデルを確認します。
- `/share` でセッションをエクスポートまたは共有する方法を学びます。
- 並列作業、ワークツリー、クラウドエージェントへの委任に使える任意のコマンドを確認します。

## シナリオ

CLI の主なワークフローを終えました。次は、コンテキストの管理、モデルの切り替え、セッションの共有、必要に応じた作業の [Copilot クラウドエージェント][about-cloud-agent]への委任など、追加機能を確認します。

## Copilot CLI のコンテキストを確認する

大規模または複雑なタスクに取り組むと、モデルの最大コンテキストウィンドウに達することがあります。Copilot CLI は必要に応じて会話を自動的に圧縮します。また、スラッシュコマンドを使って状況を確認したり、自分で圧縮したりできます。

1. Codespace に戻り、まだ Copilot CLI が開いていない場合は、リポジトリのルートから起動します。
2. 次を入力します。

   ```plaintext
   /context
   ```

3. モデル、現在のトークン使用量、システム指示、ツール、メッセージ、空き領域にコンテキストがどのように割り当てられているかを確認します。
4. 会話を圧縮します。

   ```plaintext
   /compact
   ```

5. もう一度 `/context` を入力し、結果を比較します。会話がまだ短い場合は、大きな違いがないこともあります。

> [!NOTE]
> Copilot CLI は、コンテキストウィンドウが埋まると自動的にコンテキストを圧縮します。自分でタイミングを選びたい場合は `/compact` を使ってください。関係のない別のタスクに移るときに新しい会話を始めるには、`/clear` または `/new` を使います。

## モデルを選ぶ

モデルごとに得意分野が異なり、開発者によって好みも異なります。Copilot CLI では、利用できるモデルと使用状況を確認して、使うモデルを選べます。

1. 次を入力します。

   ```plaintext
   /model
   ```

2. 利用できるモデルと使用状況の情報を確認します。
3. 現在のモデルを使い続けるか、別のモデルを選択するか、<kbd>Esc</kbd> を押して一覧を閉じます。

## セッションを共有する

チームで協力して学んだことを共有すると、AI ツールの活用方法を互いに高められます。`/share` コマンドを使うと、セッションを Markdown または HTML ファイルにエクスポートしたり、共有リンクを作成したり、GitHub gist を公開したりできます。

1. `/help` を入力し、インストール済みバージョンにある `/share` のオプションを確認します。
2. セッションを共有する場合は、ローカルの Markdown 形式で出力する `/share file` など、目的に合った方法を選びます。
3. エクスポートした内容を誰かに送ったり公開したりする前に確認します。セッションのエクスポートには、プロンプト、応答、プロジェクトの詳細が含まれることがあります。

リンクや gist の公開は任意です。チームが共有するつもりのないリポジトリや会話の内容は公開しないでください。

## 任意: 作業の並列化や委任

ワークショップの主要な内容はここまでです。Copilot CLI には、大規模なタスクに使えるコマンドもあります。

- `/fleet` は、独立したサブタスクをサブエージェントに分割して並列実行できます。
- `/worktree` は、別のタスク用に独立した Git ワークツリーを作成できます。
- `/delegate` は、Copilot クラウドエージェントにタスクを依頼できます。クラウドエージェントは非同期で作業し、プルリクエストを開くことがあります。

これらのコマンドを使うと、新たなワークツリーやリモート作業が発生する可能性があるため、任意の内容としています。試すときは、範囲を明確に定めた新しいタスクから始め、通常のワークフローで結果をレビューしてください。非同期エージェントの作業を詳しく学ぶ場合は、[クラウドエージェントのワークショップ][cloud-workshop]に進んでください。

## まとめと次のステップ

Copilot CLI のスラッシュコマンドを使うと、設定を変更したり、セッションを共有したり、内部の動作を確認したりできます。このレッスンでは、次のことを行いました。

- `/context` と `/compact` を使い、Copilot が会話のコンテキストをどう管理するかを確認しました。
- `/model` を使い、利用できるモデルを確認しました。
- `/share` でセッションをエクスポートまたは共有する方法を学びました。
- 並列作業、ワークツリー、クラウドエージェントへの委任に使える任意のコマンドを確認しました。

Copilot CLI には、まだ多くのスラッシュコマンドがあります。これまで学んだことを[振り返り][next-lesson]、次の学習方法を確認して、ワークショップを締めくくりましょう。
