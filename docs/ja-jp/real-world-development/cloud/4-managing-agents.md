これまでの 2 つの演習では、Copilot クラウドエージェントに、ユーザーエクスペリエンスの改善や機能追加に関する 3 つのタスクを依頼しました。クラウドエージェントは非同期かつ自律的に動作しますが、タスクを監視することも重要です。

クラウドエージェントに割り当てたタスクは、GitHub.com の[エージェントページ][agents-page]など、さまざまなツールで管理できます。このミッションコントロールでは、プルリクエスト (PR) が開かれているエージェントのタスクをすべて確認できます。実行内容を調べたり、進行中のセッションに追加の指示を送ったりできます。

このレッスンでは、次のことを行います。

- エージェントページでクラウドエージェントのタスクを監視します。
- 進行中のセッションに追加機能を依頼します。

## シナリオ

エージェントにハイコントラストモードの作成を依頼した後、チームはライトモードも追加したいと考えました。サイトのスタイルと切り替え機能を更新しているため、一緒に実装するのが自然です。エージェントの作業に指示を送り、ハイコントラストモードに加えてライトモードも実装してもらいましょう。

## Copilot クラウドエージェントのタスクを確認する

Copilot クラウドエージェントに割り当てたタスクの現在の状況を確認します。

1. [Copilot エージェントページ](https://github.com/copilot/agents)に移動します。
2. メインペインと左ペインの両方にあるタスク一覧を確認します。次のような、Copilot に割り当てたタスクが表示されます。
   - コードベースのドキュメントを更新する。
   - ゲームを変更する API を生成する。
   - Web サイトにハイコントラストモードを追加する。
3. 実行中のタスクを 1 つ選択し、Copilot が実行した作業を確認します。次のような内容があります。
   - リポジトリからコードをチェックアウトする。
   - Copilot が作業する環境を作成する。
   - MCP サーバーをセットアップする。
   - 割り当てられたタスクを完了するための各種手順を実行する。

> [!NOTE]
> 表示される具体的な手順は、Copilot の作業状況や進め方によって異なります。

4. 右側に表示されるプルリクエスト (PR) ペインも確認します。PR と変更されたファイルを表示し、さらに詳しく監視できます。

## クラウドエージェントに指示を送る

現在実行中のタスクを確認できました。次は、エージェントがハイコントラストモードに取り組んでいる間に、ライトモードの切り替えも追加するよう依頼します。

1. ハイコントラストモードの追加に関するセッションを選択します。エージェントが付けた名前や作業状況によって、タイトルは異なります。

   ![ミッションコントロールのアクセシビリティセッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了して作業が始まるまで、数分間セッションを確認します。下に示すようなメッセージが表示されたら作業が開始されています。
3. **Steer active session while Copilot is working** ダイアログに次のプロンプトを入力します。

   ```plaintext
   While we are working on a high contrast mode, let's also add a light mode. There should be a switch for this mode as well where users can select their desired display mode.
   ```

   ![Copilot エージェントページのタスク。作業中のアクティブセッションに指示を送るダイアログが強調されている](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを受け取り、作業に加えたことを確認します。

## Copilot に作業を任せる

前回と同じように、Copilot は更新されたタスクに取り組みます。メッセージを送信した時点で実行していた手順が終わった後に、新しい依頼を作業の流れに追加します。

今回も数分かかります。これまでに学んだことを振り返りながら待ちましょう。

## まとめと次のステップ

このレッスンでは、GitHub Copilot クラウドエージェントのタスクを監視して方向付けするための中心的な場所、Copilot エージェントページを確認しました。このミッションコントロールでは、進行中や完了済みのタスクを追跡し、実行中の作業をレビューし、作業途中のタスクに別の指示を送って範囲を調整できます。

次の内容を学びました。

- ミッションコントロールとエージェントページを使って、クラウドエージェントのタスクを監視する。
- 進行中のセッションに追加機能を依頼する。

Copilot がアクセシビリティ機能の作業を進めている間に、Copilot が作成した[プルリクエストを改善する][next-lesson]方法を確認しましょう。
